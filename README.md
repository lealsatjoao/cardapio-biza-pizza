# Cardápio Biza Pizza

Cardápio digital para consulta de mesa (dine-in) da pizzaria Biza Pizzas. React + TypeScript + Vite + Tailwind.

Veja [CONTEXTO.md](./CONTEXTO.md) para diretrizes do projeto, requisitos e histórico.

## Desenvolvimento

```
npm install
npm run dev
```

## Build

```
npm run build
```
