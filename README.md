# Cardápio Biza Pizza

Cardápio digital para consulta de mesa (dine-in) da pizzaria Biza Pizzas. React + TypeScript + Vite + Tailwind CSS v4.

🔗 **Ao vivo:** https://lealsatjoao.github.io/cardapio-biza-pizza/

Veja [CONTEXTO.md](./CONTEXTO.md) para visão geral do projeto, estrutura de arquivos e como editar o cardápio.

## Desenvolvimento

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Deploy

Automático via GitHub Actions (`.github/workflows/deploy.yml`): todo push na branch `main` builda o projeto e publica no GitHub Pages. Não é necessário rodar build/deploy manualmente.
